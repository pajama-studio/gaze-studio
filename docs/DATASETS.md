## GazeMining example provenance

Source record: DOI `10.5281/zenodo.5031618`, archive version 1.0.2. Extracted `Dataset_visual_change/p1/amazon.webm`, `amazon.json`, `amazon_times.csv`, `amazon_meta.csv` and README via HTTP byte ranges; did not require downloading the entire 4.7 GB archive.

The converter preserves the 1024×768 viewport, left eye and original floating coordinates, including off-screen gaze. It groups duplicate Qt receipt milliseconds rather than fabricating unique sub-ms timestamps. Native video has 382 VFR timestamps; these match the provided frame-time file exactly. The original datacast is preserved as a gzip attachment. Two manually authored left/right viewport AOIs are illustrative regions, not dataset ground truth or semantic product labels.

Reproduce:

```sh
python3 scripts/fetch-gazemining.py README.txt \
  Dataset_visual_change/p1/amazon.webm Dataset_visual_change/p1/amazon.json \
  Dataset_visual_change/p1/amazon_times.csv Dataset_visual_change/p1/amazon_meta.csv
python3 scripts/prepare-gazemining.py
```

Hashes, sizes, sample and frame counts: [gazemining-provenance.json](gazemining-provenance.json). The source parser was inspected at commit `54d0699ed6b3041ab990dca3ce6bcf8217f840d0` ([Parser.cpp](https://github.com/raphaelmenges/visual-stimuli-discovery/blob/54d0699ed6b3041ab990dca3ce6bcf8217f840d0/code/src/lib/Stage/Processing/Parser.cpp), [Layer.hpp](https://github.com/raphaelmenges/visual-stimuli-discovery/blob/54d0699ed6b3041ab990dca3ce6bcf8217f840d0/code/src/lib/Data/Layer.hpp)).
